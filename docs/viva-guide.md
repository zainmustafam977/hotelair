# HotelAir Viva Guide

This guide is prepared to help students explain the project confidently during a viva or presentation.

## 1. Introduction

HotelAir is a hotel management system that helps a hotel or admin team manage rooms, bookings, guests, staff, and payments from a centralized application.

## 2. Objective

The main purpose is to reduce manual effort and improve speed, organization, and control in hotel operations.

## 3. Modules in the Project

- Login and authentication
- Dashboard analytics
- Room management
- Booking management
- Guest records
- Staff records
- Payment history
- Settings page
- About page

## 4. Project Flow

1. The user opens the login page.
2. The user logs in to the system.
3. The dashboard loads key hotel information.
4. Admin manages rooms, guests, bookings, and staff.
5. The system saves and updates data in SQL Server.
6. Reports and charts display operational status.

## 5. Technologies Used

- HTML for structure
- JavaScript for logic
- Node.js and Express for backend
- SQL Server for database management

## 6. Viva Questions and Answers

### Q: What is the purpose of HotelAir?
A: It is a hotel management system that helps manage bookings, rooms, guests, staff, and payments.

### Q: Why use SQL Server?
A: SQL Server provides structured storage for records and supports reliable data management for an academic web application.

### Q: How is the project organized?
A: The project has a backend server, a database, and frontend pages in the public folder.

### Q: What is the role of the dashboard?
A: It helps the admin monitor key metrics and understand hotel operations quickly.

### Q: What are the main challenges faced?
A: Keeping the database connected, validating inputs, and ensuring the HTML pages and backend routes work together correctly.

### Q: How would you improve the project in future?
A: Add user roles, report exports, better validation, advanced analytics, and a stronger security layer.

## 7. Short Viva Summary

> HotelAir is a hotel management system built to manage operations efficiently. It includes room, booking, guest, staff, and payment modules, and it uses Node.js, Express, and SQL Server to provide an organized and practical solution for hotel administration.

## 8. Final Presentation Tips

- Explain the purpose clearly.
- Show the dashboard and modules.
- Discuss the database design.
- Mention user flow from login to operations.
- Show the importance of the project in real hotel administration.
